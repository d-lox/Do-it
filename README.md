# Do It ⚡

A clean, distraction-free task manager and focus suite designed for students who value privacy, speed, and aesthetics. 

No corporate tracking, no annoying ads, and no bloated features—just a refined space to organize your day, run your focus sessions, and get things done.

---

## ✨ Key Features

* **Pure Focus Workflow:** Minimalist task tracking, habit building, and an integrated Pomodoro timer to keep you in the zone.
* **The "Black Box" Aesthetic:** Crafted with deep obsidian dark modes, frosted glassmorphism (`BackdropFilter`), and high-contrast monochrome typography.
* **Offline-First Privacy:** Your tasks and data stay locally on your device where they belong.
* **Ecosystem Ready:** Built to seamlessly connect with local companion tools (like Synapse AI) via secure local Android intents and custom URI schemes (`doit://`).

---

## 🛠️ Tech Stack

* **Framework:** Flutter / Dart (Android)
* **Architecture:** Clean, modular local-first database state management
* **Design:** Custom glassmorphism styling and sharp geometric minimalism
